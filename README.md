# LiveCaption Desk · 实时字幕纠错台

LiveCaption Desk 是面向直播字幕校对员的长时间值守工作台。字幕按时间顺序进入待确认区，确认后进入直播区；校对员可以快速处理标点、专有名词、发言人和数字，并在弱网或断线时继续工作。

## 功能

- 实时待确认队列：按时间和序号显示字幕，支持只看需处理内容或异常优先。
- 接力校对：顶栏切换校对员身份；开始修改即占用片段（限时 30 秒，编辑自动续期），列表与编辑台实时显示每位校对员正在处理的片段和占用倒计时。
- 过期接管：他人占用到期后可显式「接管片段」，系统自动把原处理人未提交的内容快照为交接留档，可随时回溯。
- 交接冲突保护：原处理人在占用失效或被接管后再次提交会被拦截，提交内容登记为「交接冲突」并原样保留在冲突复核队列，不会覆盖接手人。
- 离线发件箱带版本：离线期间的修改/确认记录下手瞬间的片段版本（revision）与术语规则版本（rulesVersion）；恢复连接后由校对员手动「按顺序回放」。
- 冲突复核：已被他人确认、片段版本过期、术语规则版本变化或正被他人占用的旧改动不会直接进直播区，按发生顺序列出差异，可「采用待复核内容 / 保留现有版本 / 载入编辑台」裁决。
- 字幕编辑：修改发言人、正文、标点和数字；支持全角数字、中文数字及常见数字格式规范化。
- 术语快捷替换：规则可限定发言人，可一键应用到当前字幕，并记录使用次数；增删规则会递增规则版本号。
- 直播确认：使用 `⌘/Ctrl + Enter` 确认后进入直播时间线，支持导出 SRT。
- 离线校正：断线后仍可继续修改和确认（本地预占），确认内容进入离线发件箱。
- 顺序合并：恢复连接后按发生时间排序回放，并重新检查重复和过期内容；冲突交由人工裁决。
- 异常提示：重复片段、等待超过 90 秒的过期片段、最长等待时间、队列积压、占用和待裁决冲突数都会明确展示。
- 长时使用：提供深色值守界面、14–28px 字幕字号调整和清晰的键盘焦点。
- 键盘操作：`Alt + J/K` 切换片段，`⌘/Ctrl + 1–4` 插入常用标点，`⌘/Ctrl + Z` 撤销，`⇧⌘/Ctrl + Z` 重做。
- 本地持久化：所有修改、术语规则、占用/交接/冲突状态、连接模拟状态和界面字号保存在 `localStorage`，旧草稿会自动补齐接力字段。

## 技术栈

- Lit 3
- TypeScript 5
- Carbon Web Components 2
- Carbon Styles
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认监听 Vite 的 `5173` 端口。模拟队列每 5 秒自动更新。可在顶栏切换三位校对员（周恺/林越/严晓）演练交班，用「模拟断线」→（切换校对员制造他人修改）→「恢复连接」→「按顺序回放发件箱」演示离线版本冲突；初始演示中第 6 段带一个即将到期的占用，可直接体验过期接管。

## 构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。类型检查由构建命令自动执行。

## Docker

```bash
docker build -t sologsb-1011 .
docker run --rm -p 10011:80 sologsb-1011
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10011`。
