# LiveCaption Desk · 实时字幕纠错台

LiveCaption Desk 是面向直播字幕校对员的长时间值守工作台。字幕按时间顺序进入待确认区，确认后进入直播区；校对员可以快速处理标点、专有名词、发言人和数字，并在弱网或断线时继续工作。

## 功能

- 实时待确认队列：按时间和序号显示字幕，支持只看需处理内容或异常优先。
- 字幕编辑：修改发言人、正文、标点和数字；支持全角数字、中文数字及常见数字格式规范化。
- 术语快捷替换：规则可限定发言人，可一键应用到当前字幕，并记录使用次数。
- 接力校对：
  - 每位校对员有独立身份（顶栏切换），编辑片段即取得 45 秒占用，编辑自动续期；
  - 待确认卡片、编辑台和右侧“接力校对”面板实时显示各片段的处理人、第几任和占用剩余时间；
  - 他人占用中的片段只读且无法确认，占用过期后可显式接管，接管时自动为原处理人留存稿件；
  - 原处理人被接管后再提交不会覆盖，自动生成交接冲突进入“待复核”，并排展示两个版本供人工裁决；
  - 支持主动“交班释放”，同事立即接手而不必等过期。
- 离线版本恢复：离线确认带着下手时的片段版本（r 版本）和术语规则版本（v 版本）进入发件箱；恢复后按发生顺序合并，已被他人在另一端确认、或术语规则已改版的旧改动不会直接进直播区，统一列入“待复核冲突”，可选择重放、保留直播区版本、退回按新规则复核或舍弃。
- 直播确认：使用 `⌘/Ctrl + Enter` 确认后进入直播时间线，支持导出 SRT。
- 顺序合并：恢复连接后按序号和开始时间排序合并，并重新检查重复和过期内容。
- 异常提示：重复片段、等待超过 90 秒的过期片段、最长等待时间、队列积压和待复核冲突都会明确展示。
- 演示工具：右侧面板可模拟同事占用 / 交班确认、另一端确认离线片段、同事改版术语规则。
- 长时使用：提供深色值守界面、14–28px 字幕字号调整和清晰的键盘焦点。
- 键盘操作：`Alt + J/K` 切换片段，`⌘/Ctrl + 1–4` 插入常用标点，`⌘/Ctrl + Z` 撤销，`⇧⌘/Ctrl + Z` 重做。
- 本地持久化：所有修改、术语规则、占用 / 接力记录、连接模拟状态和界面字号保存在 `localStorage`。

## 技术栈

- Lit 3
- TypeScript 5
- Carbon Web Components 2
- Carbon Styles
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认监听 Vite 的 `5173` 端口。模拟队列每 5 秒自动更新，可用界面中的“模拟断线”和“恢复并合并”演示离线流程。

## 构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。类型检查由构建命令自动执行。

## Docker

```bash
docker build -t sologsb-1011 .
docker run --rm -p 10011:80 sologsb-1011
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10011`。
